# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №3.

## Что реализовано

### Flexbox
- **Навигационное меню** (`<nav>`) - горизонтальное на десктопе, вертикальное на мобильном.
- **Карточки релизов** (`.release-card`) - 4 в ряд на десктопе, 2 на планшете, 1 на мобильном.
- **Форма обратной связи** (`.contact-form`) - вертикальный flex-контейнер.

### CSS Grid
- **Дашборд «Студийное оборудование»** (`.equipment-grid`) - 3 колонки × 2 строки на десктопе.
- Семантические карточки выполнены через `<figure>` + `<figcaption>`.

### Адаптивность
- **Медиа-запросы:**
  - `@media (min-width: 993px)` - 4 карточки релизов в ряд.
  - `@media (max-width: 992px)` - планшет: 2 карточки, 2 колонки оборудования.
  - `@media (max-width: 576px)` - мобильный: 1 карточка, 1 колонка, вертикальное меню.
- **Защита от горизонтальной прокрутки:** `box-sizing: border-box`, `overflow-x: hidden`, `img { max-width: 100%; }`.
- **Адаптивные изображения:** `aspect-ratio` вместо фиксированной высоты.
